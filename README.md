## 🧠 Who Am I?

I'm a developer, builder, and technology enthusiast who doesn't stay inside one stack. My curiosity tends to move like this:

```text
SOFTWARE → BACKEND & MOBILE → NETWORKS → HARDWARE & CLOUD → AI → AUTOMATION
```

And sometimes all of them end up in the same project.

🎓 Computer Science & Engineering — **BPMCE, Madhepura**

---

## ⚡ How I Think

I don't start by asking *"what technology should I use?"* — I start with *"what problem are we trying to solve?"* and figure out the rest from there.

> If it needs a physical button wired to a server, I'll probably build that too.
> And I definitely won't forget the colors and animations. 😎
